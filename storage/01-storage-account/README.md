# Lab 01 - Azure Storage Account

## Objective

The objective of this lab is to create and configure an Azure Storage Account using the Azure Portal while understanding the core concepts of Azure Storage.

This lab introduces the foundation of Azure Storage services that will be used throughout the remaining storage labs.

---

## Learning Objectives

After completing this lab, you should be able to:

- Create a Resource Group
- Create an Azure Storage Account
- Understand storage account naming requirements
- Configure storage performance options
- Select redundancy options
- Understand security and encryption settings
- Navigate the Storage Account portal
- Validate successful deployment

---

## Azure Services Used

- Azure Resource Group
- Azure Storage Account

---

## Prerequisites

- Active Azure Subscription
- Azure Portal access
- Basic understanding of Azure Resource Groups
