# Lab 05 - Azure Table Storage

## Objective

The objective of this lab is to create and manage Azure Table Storage using an existing Azure Storage Account. You will learn how Azure Table Storage organizes structured NoSQL data using PartitionKey and RowKey while performing common CRUD operations.

This lab introduces Azure Table Storage and demonstrates how it can be used to store scalable, schema-less application data.

---

## Learning Objectives

After completing this lab, you should be able to:

- Create an Azure Table
- Understand entities and properties
- Understand PartitionKey and RowKey
- Insert entities into a table
- Query entities
- Update entities
- Delete entities
- Navigate Azure Table Storage using the Azure Portal
- Understand common use cases for Azure Table Storage
