# Azure Portal Steps

## Objective

Create an Azure Table Storage table using the Azure Portal.

---

## Step 1

Sign in to:

https://portal.azure.com

---

## Step 2

Search for:

Storage Accounts

---

## Step 3

Select your storage account.

Example:

ppststorageaccount

---

## Step 4

From the left navigation menu:

Data Storage

↓

Tables

---

## Step 5

Click

+ Table

---

## Step 6

Enter

Table Name

Example:

customers

---

## Step 7

Click

OK

---

## Step 8

Verify

The table should now appear in the Tables list.

---

## Step 9

Open the table.

Initially it will contain zero entities.

---

## Step 10

(Optional)

Add entities using:

Storage Explorer

Azure SDK

Azure CLI

REST API

---

## Validation Checklist

✔ Storage Account exists

✔ Table created successfully

✔ Table visible in Azure Portal

✔ No deployment errors

---

## Cleanup

If this was a practice lab:

Delete the table

or

Delete the resource group.
