## Major Learning Themes

### 1. Resource Management vs Access Management

Contributor:

- Manage Azure resources
- Does not automatically provide RBAC role-assignment capability

User Access Administrator:

- Access-management responsibility

Owner:

- Resource management + access management

Key permission:

Microsoft.Authorization/roleAssignments/write

---

### 2. Management Plane vs Data Plane

Management-plane examples:

- Configure Storage Account
- Manage Azure resources
- Create containers

Data-plane examples:

- Download blob
- Read blob contents
- Write blob data

Important distinction:

Contributor
    !=
Storage Blob Data Reader

Reader
    !=
Storage Blob Data Reader

---

### 3. Microsoft Entra VM Login

Contributor on a VM does not automatically provide guest OS login.

Use:

Virtual Machine User Login
    ->
Normal guest OS access

Virtual Machine Administrator Login
    ->
Administrative guest OS access

Use Microsoft Entra security groups for centralized access management.

---

### 4. User-Assigned Managed Identity

UAMI has an independent lifecycle.

Deleting the workload:

    does not automatically delete UAMI

Recreating the workload:

    does not automatically attach UAMI

Key lesson:

"UAMI survives the workload, but the workload does not automatically come back with the UAMI attached."
