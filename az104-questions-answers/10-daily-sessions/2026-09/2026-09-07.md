## Key Corrections

### 1. Private Endpoint vs Service Endpoint

Private Endpoint provides a private IP address in the VNet for the Storage service.

Mental model:

Private Endpoint = how traffic reaches the service

RBAC = what the identity can do

### 2. Access Key vs Managed Identity

For Azure-hosted applications, prefer Managed Identity with Microsoft Entra ID and Azure RBAC rather than long-lived Storage Account access keys.

SAS remains useful for temporary or delegated access.

### 3. GRS vs RA-GRS vs Failover

GRS provides geo-replication to a secondary region.

RA-GRS additionally provides read access to the secondary.

Failover promotes the secondary to the primary.

### 4. Private Endpoint 403 Troubleshooting

When a previously working application starts returning 403 after Private Endpoint configuration and public access is disabled, investigate the network and DNS path.

Sequence:

1. Verify Private Endpoint connection status.
2. Verify private DNS configuration.
3. Verify Storage hostname resolution.
4. Verify VNet connectivity.
5. Verify Storage networking configuration.
6. Re-check RBAC after network configuration is confirmed.

### 5. Blob Lifecycle Management
